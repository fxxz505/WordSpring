# WordSpring

一款为英语学习设计的离线背单词应用。用一张张可翻转、可滑动的词卡，建立自己的
复习节奏；学习记录保留在手机本地，无需注册账号。

**当前版本：** 1.0.0

**适用系统：** Android 8.0 及以上

## 安装方法

1. 用手机浏览器下载上方 APK 文件。
2. 下载完成后，打开通知栏或“下载”文件夹，点击 APK。
3. 如果系统提示“禁止安装未知应用”，点击“设置”，允许当前浏览器或文件管理器
   安装应用，然后返回继续安装。
4. 安装完成后，点击“打开”即可开始使用。

如果安装时提示“应用未安装”，请确认手机为 Android 8.0 或更高版本，并删除此前
下载不完整的 APK 后重新下载。

## 第一次使用

首次打开时，依次完成以下设置：

1. 选择学习目标和一套词书。
2. 选择每日新学单词数量，或在词书详情中选择计划完成日期。
3. 开始当天学习。首页会分别显示“新学”和“复习”的建议数量。

复习数量由已经学过单词的遗忘规律自动安排，无需手动设置。当天完成后，明天继续
打开应用即可接着学习。

## 词卡怎么用

词卡正面只显示英文单词，帮助你先自行回忆含义。点击卡片可以翻面，查看中文释义、
词性和其他信息；卡片翻开时会尝试播放一次英文发音。

翻开卡片后，用滑动动作记录记忆情况：

| 动作 | 表示 | 卡片提示色 | 结果 |
| --- | --- | --- | --- |
| 向右滑 | 不记得 | 红色 | 这张词会更快再次出现 |
| 向上滑 | 模糊 | 橙色 | 会安排较近的一次复习 |
| 向左滑 | 记得 | 绿色 | 下次复习间隔会更长 |

滑动完成后会自动进入下一张卡片，不需要点击“继续”。每张新卡开始时都会恢复到正面，
避免上一次的滑动或翻转状态影响下一张卡。

## 发音功能

翻开词卡后，点击卡片中的播放图标可再次播放单词发音。发音由手机已安装的系统
文字转语音服务提供。

如果没有声音：

1. 检查手机媒体音量是否打开。
2. 到手机“设置”中检查是否已安装并启用英语文字转语音引擎。
3. 重新打开 WordSpring 后再试一次。

不同品牌手机的系统发音效果可能不同；WordSpring 不会上传你的学习数据来获取发音。

## 词书与学习计划

应用内置 8 本离线词书，每本都严格对应 ECDICT 中该考试标签下的词表，不掺入其他词表的
凑数单词，并按词频从常用到少用排列：

| 词书 | 词数 | 默认每日新词 |
| --- | ---: | ---: |
| 中考英语词汇 | 1603 | 10 |
| 高考英语词汇 | 3677 | 15 |
| 大学英语四级词汇（新用户默认） | 3849 | 15 |
| 大学英语六级词汇 | 5407 | 20 |
| 考研英语词汇 | 4801 | 20 |
| 雅思 IELTS 词汇 | 5040 | 20 |
| 托福 TOEFL 词汇 | 6974 | 20 |
| GRE 词汇 | 7504 | 20 |

每个词条包含标准 IPA 音标、按词性分组的中文释义，以及过去式、复数、比较级等词形变化。
首次引导时可以直接选择要学的词书；之后可在“词书”页随时启用或停用，查看词数、学习
进度和计划设置。旧版本的 “WordSpring Complete 4500” 会在升级时自动合并到四级词书，
已学进度和复习记录都会保留。

选择完成日期后，应用会计算每天建议学习的新词数量，并提供预览；你也可以按自己的
时间调整每日新词数。首页的“新学”显示当天应学习的全部新词，“复习”显示当天到期
需要巩固的词数，两者分别计算。

## 数据与隐私

- 学习记录、进度和自定义词书默认只保存在手机本地。
- 不需要账号，也不会自动将学习数据上传到云端。
- 可在“设置”中主动备份学习数据，或从备份恢复。
- 卸载应用会清除本地学习数据；重要进度请先完成备份。

## 更新应用

新版本会发布在 [版本下载页](https://github.com/fxxz505/WordSpring/releases)。更新时请下载
最新 APK 后直接安装覆盖旧版本。

**不要先卸载旧版。** 覆盖安装通常可以保留学习进度；卸载后再安装会清除保存在手机
本地的学习数据。若系统提示无法更新，请确认下载的是本项目的新版 APK，并且没有
安装其他来源、同名但签名不同的应用。

## 常见问题

### 为什么首页的复习数量会变化？

复习量会根据已学习单词的到期时间自动更新。答题选择“不记得”或“模糊”后，单词会
更早回到复习队列；选择“记得”后，复习间隔会变长。

### 为什么最后一张词卡没有马上重复出现？

每个学习组按设定的数量完成后会结束本轮学习。选择“不记得”的单词会被记录，并在
后续复习中按计划再次出现，不会让当前学习组的总数发生变化。

### 可以横屏使用吗？

WordSpring 以竖屏词卡学习为主，建议保持竖屏使用，以获得完整、稳定的卡片体验。
