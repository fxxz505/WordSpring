# ECDICT Free Vocabulary Import

WordSpring supports offline UTF-8 CSV import. For an openly licensed English-Chinese
source, use [ECDICT](https://github.com/skywind3000/ECDICT), whose repository is MIT licensed.
Obtain the upstream `stardict.csv` yourself, then convert only the list needed:

```powershell
python .\tools\convert_ecdict.py <path-to-stardict.csv> .\cet4.csv --tag cet4
python .\tools\convert_ecdict.py <path-to-stardict.csv> .\cet6.csv --tag cet6
python .\tools\convert_ecdict.py <path-to-stardict.csv> .\gaokao.csv --tag gk
```

Import the resulting CSV from a word book's **Import CSV** action. Keep the generated
`LICENSE-ECDICT.txt` with every redistributed converted list. ECDICT's README notes that
its entries are assembled from several resources, so review upstream provenance before
shipping a large derivative word-list in a public release.

## Built-in word books

Built-in books live in `app/src/main/assets/books/<folder>/` (`metadata.json`,
`entries.json`, `LICENSE.txt`) and are generated by `tools/build_wordbooks.py`:

```bash
python tools/build_wordbooks.py --csv .cache/ecdict.csv --out app/src/main/assets/books
```

Each book is **exactly** the set of ECDICT entries carrying one exam tag. No filler words
from other lists are added. Entries are ordered by corpus frequency (ECDICT `frq`/`bnc`,
most common first).

| Folder | Name | ECDICT tag | Words |
| --- | --- | --- | ---: |
| zhongkao | 中考英语词汇 | `zk` | 1603 |
| gaokao | 高考英语词汇 | `gk` | 3677 |
| cet4 | 大学英语四级词汇 (default) | `cet4` | 3849 |
| cet6 | 大学英语六级词汇 | `cet6` | 5407 |
| kaoyan | 考研英语词汇 | `ky` | 4801 |
| ielts | 雅思 IELTS 词汇 | `ielts` | 5040 |
| toefl | 托福 TOEFL 词汇 | `toefl` | 6974 |
| gre | GRE 词汇 | `gre` | 7504 |

Entry format (asset version 3.x):

```json
{"word":"abandon","phonetic":"/əˈbændən/",
 "senses":[{"pos":"vt.","zh":"放弃；抛弃；遗弃"},{"pos":"n.","zh":"放任；狂热"}],
 "forms":"p:abandoned/d:abandoned/i:abandoning/3:abandons"}
```

Cleaning rules:

- `translation` is split into lines and grouped by part of speech (`a.` becomes `adj.`),
  with at most 8 meanings per part of speech.
- Technical-domain lines such as `[计] …` or `[医] …` and inflection notes such as
  `run的过去式` are dropped. Inflections come from `exchange` and are shown on the card.
- Phonetics are normalised to IPA and wrapped in `/…/`.
- `exchange` is reduced to `p d i 3 s r t` (past tense, past participle, present participle,
  third person singular, plural, comparative, superlative).

On startup `StarterBookImporter` syncs the catalog (`BuiltInBookCatalog`):

- A new install imports all books and enables only CET-4.
- If an asset version changes, the book is diffed in place: kept words keep their review
  progress, removed words are dropped, and new words become NEW cards.
- Built-in meanings are tagged `BUILT_IN` and replaced on upgrade, so a word shared by
  several books never accumulates duplicate meanings. User-imported meanings are kept.
- The legacy "WordSpring Complete 4500" book is merged into CET-4 with progress and review
  history, then removed.

These lists follow ECDICT's exam tags and are study aids, not official exam syllabi.
